# Point Cloud Editor

Clean-room WebGPU point cloud viewer/editor. 5–20M point LiDAR, WGSL compute, editing, explicit perf numbers.

## Status
Phase 0: scaffold + spike.

## Setup
npm install
npm run dev        # Chrome with WebGPU
npm test
npm run build

## Spike params
`?n=2000000&size=3` — point count, point size px.
